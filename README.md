# CineApp - Multicinema

CineApp es una aplicación móvil desarrollada en Kotlin para Android como proyecto académico de la asignatura Desarrollo de Software para Móviles de la Universidad Don Bosco.

La aplicación está inspirada en Multicinema y permite consultar películas, seleccionar funciones y asientos, y simular la compra de boletos para los complejos de Plaza Mundo Apopa y Plaza Mundo Soyapango.
